# Калькулятор юнит-экономики одежды

Одностраничное приложение (`index.html`): расчёт маржи, ROI и себестоимости, раздел «Номенклатура» с импортом и экспортом Excel.
Работает в браузере, данные хранятся на устройстве.

## Структура
- `index.html` — всё приложение
- `sw.js`, `manifest.json`, `icon-*.png` — установка на экран телефона и работа офлайн
- `nomenclature_template.xlsx` — шаблон таблицы для импорта

## Публикация на GitHub Pages
Settings → Pages → Source: `Deploy from a branch`, Branch: `main`, folder: `/ (root)`.

## Обновление
Запустите `./publish.sh "что изменилось"` — скрипт сохранит изменения и отправит их на GitHub.
